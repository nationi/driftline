# Driftline artwork

The **Split D** symbol is a capital D separated along a horizontal line, with
its lower half drifting left. It identifies this independently maintained fork;
upstream driftwm attribution remains in the project README and license.

| File | Use |
| --- | --- |
| [driftline-logo.svg](driftline-logo.svg) | Horizontal logo on white or light backgrounds |
| [driftline-logo-dark.svg](driftline-logo-dark.svg) | Horizontal logo on dark backgrounds |
| [driftline-symbol.svg](driftline-symbol.svg) | Green symbol on light backgrounds |
| [driftline-symbol-black.svg](driftline-symbol-black.svg) | Dark monochrome symbol |
| [driftline-symbol-white.svg](driftline-symbol-white.svg) | Reversed symbol on dark backgrounds |
| [driftline-icon.svg](driftline-icon.svg) | Session icon; installed in the hicolor icon theme |

The light-background green is `#087F6C`; the dark-background mint is `#79D4C2`.
Neutrals are `#101820` and `#F2F5F4`. Use the supplied light/dark variants rather
than mint on white. Keep at least one stem width of clear space around visible
artwork. Display the symbol at 16 px or larger and the horizontal logo at 180 px
or larger. Preserve its proportions, gap and offset; do not add shadows or gradients.

All artwork is SVG with filled outlines, no embedded bitmaps, filters or font
runtime dependencies. The wordmark uses outlined, manually spaced Noto Sans Bold
(The Noto Project Authors, SIL Open Font License 1.1); no font software is bundled.
The original symbol and assembled artwork are distributed under the project's
[GPL-3.0-or-later license](../LICENSE).
